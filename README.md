# Customer Shopping Behavior Analysis

An End-to-End Data Analytics Project using Python, SQL, PostgreSQL & Power BI.

## Project Overview

This project focuses on analyzing customer shopping behavior to identify purchasing trends, customer preferences, and factors influencing retail sales.

Using Python, SQL, and Power BI, raw customer data is transformed into meaningful business insights to support data-driven decision-making.

## Business Objectives

- Analyze customer purchasing patterns.
- Identify top-performing product categories.
- Evaluate the impact of discounts on purchases.
- Understand customer loyalty and subscription behavior.
- Segment customers based on purchasing history.
- Generate actionable business recommendations.

## Tools & Technologies

- Python – Data Cleaning and EDA
- Pandas & NumPy – Data Manipulation
- Jupyter Notebook – Data Analysis
- PostgreSQL – Database Management
- SQL – Business Analysis
- Power BI – Dashboard Development
- GitHub – Project Documentation

## Dataset Description

The dataset contains 3,900 customer records and 18 columns, including:

- Customer ID, Age, Gender
- Item Purchased and Category
- Purchase Amount and Location
- Season, Size and Color
- Review Rating
- Subscription Status
- Discount and Promo Code Usage
- Previous Purchases
- Payment Method and Shipping Type
- Purchase Frequency

## Project Workflow

### 1. Data Loading & Exploratory Data Analysis (Python)

- Imported data using Pandas.
- Examined dataset structure and statistical summaries.
- Identified missing values and inconsistencies.
- Explored customer demographics and purchasing trends.

### 2. Data Cleaning & Transformation

- Handled missing values.
- Standardized column names and data formats.
- Created additional features for customer segmentation.
- Prepared the dataset for SQL analysis.

### 3. SQL Business Analysis (PostgreSQL)

Performed SQL queries to answer business questions:

- Revenue contribution by gender.
- Subscriber vs. non-subscriber comparison.
- Products dependent on discounts.
- Customer segmentation into New, Returning, and Loyal.
- Top 3 products within each category.
- Customer purchasing and subscription trends.

**SQL Concepts:** Joins, GROUP BY, HAVING, CASE WHEN, CTEs, Subqueries, Aggregate Functions, and Window Functions.

### 4. Power BI Dashboard

Developed an interactive dashboard featuring:

- Total Customers
- Average Purchase Amount
- Average Review Rating
- Revenue Analysis
- Product Category Performance
- Customer Demographics
- Subscription Analysis
- Customer Segmentation

### 5. Business Insights & Recommendations

- Strengthen customer loyalty programs.
- Improve subscription conversion strategies.
- Optimize discount and promotional campaigns.
- Focus on high-performing product categories.
- Develop targeted marketing strategies.

## Key Learnings
